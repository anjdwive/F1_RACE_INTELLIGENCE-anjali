🏎️ Formula 1 Race Intelligence Dashboard

📌 Project Overview

The Formula 1 Race Intelligence Dashboard is a data visualization project developed using Tableau. It provides insights into Formula 1 racing data, helping users explore race performance, driver performance, team performance, pit stops, and circuit-related information through graphical representations.

🎯 Project Objectives

* Analyze Formula 1 race performance.
* Explore driver and team performance.
* Visualize pit-stop and circuit-related information.
* Present racing data through interactive charts and graphs.
* Make Formula 1 data easier to understand using Tableau.

🛠️ Tools and Technologies

* Tableau Public — Dashboard development and data visualization.
* Microsoft Excel — Data handling and preparation.
* GitHub — Project hosting and documentation.
